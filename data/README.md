# data

- `input/pdfs/`: hier kommen die Magazin-PDFs hinein
- `input/manifests/`: optionale manuelle Artikeldefinitionen
- `input/translations/<locale>/`: optionale manuelle Übersetzungen pro Artikel
- `output/library.json`: aggregierter Suchindex
- `output/articles/*.json`: vollständige Artikel
- `output/magazines/*.json`: Magazin-Metadaten
- `output/previews/*.png`: Vorschaubilder der Startseiten
- `output/drafts/*.json`: automatisch erkannte, überprüfbare Artikelentwürfe
